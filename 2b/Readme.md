# Отчет по заданию 2b: Сегментация облака точек

## 1. Цель работы
Изучение методов фильтрации и сегментации трехмерных данных с использованием библиотеки NumPy. В ходе работы были реализованы алгоритмы выделения точек по координатным границам, высоте и расстоянию до центра.

## 2. Описание выделенных областей
В ходе работы из исходного облака (100,000 точек в кубе 100x100x100) были выделены следующие сегменты:

1.  **Bounding Box (Параллелепипед):**
    * Границы: X[20, 50], Y[30, 70], Z[10, 40].
    * Цель: Выделение конкретной прямоугольной под-области пространства.
2.  **Высокие точки (High Points):**
    * Условие: Z > 80.
    * Цель: Сегментация "верхнего слоя" облака (аналог выделения крон деревьев или крыш зданий).
3.  **Сферическая область (Near Center):**
    * Центр: (50, 50, 50), Радиус: 25.
    * Цель: Выделение точек, равноудаленных от заданного центра.



## 3. Статистика фильтрации
| Фильтр            | Условие                    | Кол-во точек после | % от оригинала |
|-------------------|----------------------------|--------------------|----------------|
| Оригинал          | -                          | 100,000            | 100%           |
| Bounding Box      | X(20-50), Y(30-70), Z(10-40) | ~3,600* | ~3.6%          |
| По высоте         | Z > 80                     | ~20,000* | ~20%           |
| По расстоянию     | Radius = 25                | ~6,500* | ~6.5%          |

*\*Примечание: точное количество зависит от случайной генерации.*

## 4. Сравнение результатов
* **Bounding Box** наиболее эффективен, когда нужно строго ограничить область по осям (например, выбрать одну комнату в здании).
* **Фильтрация по высоте** — это простейший способ удаления "земли" или выделения объектов определенного роста.
* **Фильтрация по расстоянию** создает гладкую сферическую выборку, что полезно для анализа локальной плотности вокруг датчика.

## 5. Выводы
Использование логического индексирования (масок) NumPy позволяет обрабатывать массивы из сотен тысяч точек практически мгновенно. Это является базой для более сложных алгоритмов, таких как RANSAC или кластеризация (DBSCAN).
